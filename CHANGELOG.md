# Changelog

Todas as mudanças relevantes do DejotaCode serão registradas neste arquivo.

## [1.0.0] - 2026-09-09

### Adicionado

- Site público em Astro SSG publicado no Cloudflare Pages.
- API Hono publicada no Cloudflare Workers.
- CMS administrativo com autenticação, conteúdos, categorias e métricas.
- Cloudflare D1 de produção com 21 conteúdos publicados.
- Biblioteca de mídia integrada ao Cloudflare R2.
- Upload múltiplo de arquivos no painel administrativo.
- 21 capas editoriais definitivas em 1200 × 675.
- Sitemap, RSS, robots.txt e metadados sociais.
- Preflight e scripts de deploy para produção.

### Segurança

- Rate limiting para autenticação, formulários e analytics.
- Cookies seguros, proteção CSRF e headers HTTP de segurança.
- Dependências auditadas sem vulnerabilidades conhecidas.
- Scripts nativos de instalação explicitamente permitidos.
- Backups do ambiente preview e da produção legada antes da migração.
