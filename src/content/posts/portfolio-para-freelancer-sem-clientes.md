“Como vou conseguir cliente se não tenho portfólio?”

“Como vou ter portfólio se nunca tive cliente?”

Esse ciclo trava muita gente.

A solução é simples: **portfólio não precisa começar com trabalho pago**.

Você pode mostrar projetos próprios, estudos e soluções demonstrativas, desde que deixe claro o contexto.

## O que um portfólio precisa provar?

Não precisa provar que você é especialista.

Precisa mostrar:

- o que sabe fazer;
- como pensa;
- como apresenta resultado;
- se conclui projetos;
- como documenta escolhas.

## Projeto fictício pode entrar?

Sim, se for identificado como demonstrativo.

Exemplo:

> Projeto de estudo — landing page fictícia para uma cafeteria.

O problema não é ser fictício.

O problema é fingir que foi um cliente real.

## Escolha poucos projetos

Três bons projetos podem valer mais que quinze incompletos.

Para cada um, explique:

1. contexto;
2. objetivo;
3. sua solução;
4. tecnologias;
5. desafios;
6. resultado;
7. o que aprendeu.

## Projeto 1 — algo simples e completo

Crie algo que consiga terminar.

Exemplos:

- página pessoal;
- landing page;
- catálogo;
- site de profissional fictício;
- ferramenta pequena.

Se está começando em web, veja [como escolher seu primeiro projeto de portfólio](/blog/escolher-primeiro-projeto-portfolio/).

## Projeto 2 — melhoria de algo

Pegue um projeto anterior e melhore:

- responsividade;
- acessibilidade;
- organização;
- performance;
- documentação.

Isso mostra evolução.

## Projeto 3 — problema de negócio

Crie algo ligado ao serviço que pretende vender.

Se quer atender pequenos negócios, faça uma demonstração para esse público.

Por exemplo:

- landing page de profissional;
- página de restaurante;
- página de serviço local.

## Mostre o processo

Portfólio não é só screenshot.

Inclua:

- objetivo;
- wireframe;
- decisões;
- limitações;
- antes/depois quando real;
- link do projeto;
- repositório, se apropriado.

## Não invente métricas

Evite:

> Aumentou vendas em 300%.

se isso não aconteceu.

Se é demonstrativo, diga:

> O objetivo do projeto foi praticar estrutura, responsividade e CTA.

Honestidade fortalece credibilidade.

## Não invente depoimentos

Depoimento falso destrói confiança.

Se ninguém contratou você ainda, não use depoimentos.

Use explicações de projeto.

## Use GitHub quando fizer sentido

Para programação, um repositório pode mostrar:

- commits;
- README;
- organização;
- código.

Se Git ainda é novo para você, leia [Git e GitHub: entenda a diferença](/blog/git-e-github-entenda-a-diferenca/).

## Publique os projetos

Um projeto acessível por URL facilita avaliação.

Não precisa ter domínio próprio para cada um.

Pode usar hospedagem gratuita compatível.

## Seu portfólio também é um projeto

Crie uma página que tenha:

- apresentação curta;
- projetos;
- habilidades;
- serviços;
- contato.

No DejotaCode, a [página de Portfólio](/portfolio/) segue esse princípio: projeto, contexto e aprendizados.

## O que escrever em cada card

Um card pode ter:

- nome;
- tipo;
- resumo;
- tecnologias;
- link.

Depois, uma página completa pode explicar mais.

## Evite excesso de tecnologias

Não coloque uma lista enorme apenas porque conhece os nomes.

Destaque ferramentas realmente usadas nos projetos.

## Atualize conforme evolui

O portfólio não é arquivo morto.

Remova projetos muito fracos.

Atualize os melhores.

Adicione trabalhos reais quando tiver autorização.

## E trabalhos de cliente?

Antes de publicar:

- peça autorização;
- remova dados sensíveis;
- não exponha acessos;
- não publique material confidencial.

Explique sua participação.

## Crie uma narrativa

Uma boa sequência pode ser:

1. projeto inicial;
2. projeto melhorado;
3. projeto ligado a negócio.

Isso mostra progressão.

## Checklist do portfólio inicial

- ☐ pelo menos 2 projetos concluídos;
- ☐ cada projeto tem objetivo;
- ☐ projetos fictícios identificados;
- ☐ links funcionam;
- ☐ mobile funciona;
- ☐ não existem métricas falsas;
- ☐ contato está visível;
- ☐ texto explica sua participação;
- ☐ tecnologias são reais.

## Próximo passo

Depois do portfólio, você pode montar uma oferta específica como [landing page para pequenos negócios](/blog/landing-page-para-pequenos-negocios-o-que-entregar/).

Você não precisa esperar clientes para criar evidência.

Crie projetos reais de estudo e conte a verdade sobre eles.
