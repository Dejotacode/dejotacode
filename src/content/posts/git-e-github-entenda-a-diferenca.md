Git e GitHub trabalham juntos, mas não são a mesma coisa.

## O que é Git

Git registra o histórico dos arquivos no seu computador. Cada commit funciona como um ponto identificado da evolução do projeto.

## O que é GitHub

GitHub hospeda repositórios Git na internet e acrescenta recursos para colaboração, revisão e organização do trabalho.

## Um fluxo básico

1. Altere um arquivo do projeto.
2. Confira as mudanças com `git status`.
3. Prepare os arquivos com `git add`.
4. Registre o ponto do histórico com `git commit`.
5. Envie os commits ao repositório remoto com `git push`.

Antes de executar um comando, entenda quais arquivos ele alcança. Esse cuidado torna o versionamento mais previsível e ajuda quando você começa a organizar seu [primeiro projeto de portfólio](/blog/escolher-primeiro-projeto-portfolio/).
