Um bom prompt não precisa ser longo.

Ele precisa reduzir ambiguidades suficientes para que a ferramenta entenda **o que você quer, para quem é a resposta e quais limites precisam ser respeitados**.

Se ainda estiver começando no tema, leia antes [O que é IA generativa](/blog/o-que-e-ia-generativa/).

## Comece pelo objetivo

Em vez de escrever:

```text
Explique Git.
```

diga o que você quer conseguir:

```text
Explique Git para alguém que nunca usou controle de versão.
Quero entender commit, branch e push antes de praticar no terminal.
```

Agora a ferramenta sabe o nível e o resultado esperado.

## Adicione contexto útil

Contexto só é útil quando muda a resposta.

Exemplo:

```text
Estou estudando JavaScript há uma semana.
Já entendo variáveis e funções.
Crie 5 exercícios curtos sobre condições, do mais simples ao mais difícil.
```

Informar seu nível evita explicações avançadas demais ou repetição do que você já sabe.

## Defina restrições

Restrições ajudam a impedir que a resposta siga um caminho que você não quer.

Por exemplo:

```text
Explique sem usar frameworks.
Use apenas JavaScript puro.
Não entregue a solução completa do exercício de primeira.
```

Você também pode definir limites de tamanho, linguagem, ferramentas permitidas e riscos que precisam ser evitados.

## Peça o formato certo

O formato deve combinar com o que você pretende fazer depois.

Você pode pedir:

- passos numerados para executar;
- tabela para comparar;
- checklist para revisar;
- perguntas e respostas para estudar;
- exemplo seguido de exercício;
- resumo curto antes de uma explicação detalhada.

Exemplo:

```text
Explique autenticação em dois fatores em linguagem simples.
Depois crie um checklist de 5 itens para eu aplicar hoje.
```

## Um modelo simples de prompt

Use esta estrutura:

1. objetivo;
2. contexto;
3. restrições;
4. formato desejado.

Exemplo:

```text
Objetivo: quero entender permissões no Linux.
Contexto: sou iniciante e já conheço ls e cd.
Restrições: não use comandos destrutivos.
Formato: explique com uma analogia, mostre 2 exemplos e termine com um exercício seguro.
```

Isso já resolve boa parte dos pedidos cotidianos.

## Peça critérios, não só conclusões

Para decisões, peça os critérios usados.

```text
Compare duas abordagens para este problema.
Mostre vantagens, limitações e em que cenário cada uma faz sentido.
Não escolha por mim.
```

Isso facilita revisar a resposta e tomar sua própria decisão.

## Peça para separar certeza de suposição

Quando a tarefa envolve fatos, você pode pedir:

```text
Separe fatos verificáveis, suposições e pontos que precisam de confirmação.
```

Isso não garante precisão, mas deixa a resposta mais fácil de auditar.

## Itere com base no resultado

Prompting funciona melhor como conversa.

Se a resposta estiver genérica:

```text
Dê um exemplo concreto usando um projeto pequeno.
```

Se estiver avançada demais:

```text
Explique novamente para alguém que está no primeiro mês de estudo.
```

Se estiver longa:

```text
Resuma em 5 passos e mantenha apenas o essencial.
```

A segunda pergunta pode ser mais importante do que a primeira.

## Evite juntar tarefas demais

Um prompt como:

```text
Crie um site, escreva o marketing, faça SEO, configure o banco, publique e crie anúncios.
```

mistura muitas decisões.

Dividir em etapas torna mais fácil revisar o resultado e descobrir onde algo deu errado.

## Cuidado com prompts copiados

Prompts prontos podem ajudar como inspiração, mas não são fórmulas universais.

Antes de copiar um prompt enorme, pergunte:

- qual parte realmente é necessária?
- ele foi escrito para a mesma tarefa?
- existem instruções conflitantes?
- você entende o que ele está pedindo?

Quanto mais você entende a tarefa, menos depende de “prompts mágicos”.

## Faça um exercício

Escolha uma dúvida real de estudo.

Primeiro escreva uma versão de uma linha.

Depois reescreva usando:

- objetivo;
- contexto;
- restrição;
- formato.

Compare as duas respostas.

Observe não apenas qual ficou “mais bonita”, mas qual ficou mais útil para a ação que você precisava executar.
