Sitemap XML e sitemap HTML não são a mesma coisa.

O XML é um formato feito para informar URLs aos mecanismos de busca. Uma página HTML é uma página navegável, pensada principalmente para pessoas e arquitetura do site.

## O que o Google recomenda para sitemap

O Google aceita formatos definidos pelo protocolo de sitemaps e destaca o XML como formato versátil. Ele não exige uma página HTML chamada sitemap para indexar um site bem estruturado.

## Quando uma página HTML pode ajudar

Ela pode ser útil em sites grandes, estruturas profundas ou projetos em que usuários se beneficiam de uma lista organizada de áreas importantes.

## Quando vira remendo

Se a única forma de chegar a uma página é por um sitemap HTML, o problema pode estar na navegação e nos links internos. Conteúdo importante deve estar integrado à arquitetura normal.

## No DejotaCode

Antes de criar uma página adicional, devemos verificar se categorias, trilhas, Store, busca e links contextuais já oferecem descoberta suficiente.
