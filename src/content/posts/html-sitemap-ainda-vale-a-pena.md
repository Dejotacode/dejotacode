Sitemap XML e sitemap HTML não são a mesma coisa.

O XML é um formato feito para informar URLs aos mecanismos de busca. Uma página HTML é uma página navegável, pensada principalmente para pessoas e arquitetura do site.

## O que o Google recomenda para sitemap

O Google aceita formatos definidos pelo protocolo de sitemaps e destaca o XML como formato versátil. Ele não exige uma página HTML chamada sitemap para indexar um site bem estruturado.

## Quando uma página HTML pode ajudar

Ela pode ser útil em sites grandes, estruturas profundas ou projetos em que usuários se beneficiam de uma lista organizada de áreas importantes.

## Quando vira remendo

Se a única forma de chegar a uma página é por um sitemap HTML, o problema pode estar na navegação e nos links internos. Conteúdo importante deve estar integrado à arquitetura normal.

## Um exemplo de decisão

Imagine um site com documentação, cursos e artigos antigos. Uma página HTML agrupando essas áreas pode ajudar uma pessoa que não sabe o nome exato do conteúdo. Ela deve ter títulos claros e links úteis, em vez de repetir centenas de URLs sem organização.

| Situação | Ação mais útil |
|---|---|
| Usuário não encontra uma seção | Melhorar menus, busca e agrupamentos |
| Site tem muitas áreas e uma visão geral ajuda | Considerar um índice HTML organizado |
| Mecanismo de busca precisa descobrir URLs | Manter sitemap XML correto e links rastreáveis |
| Página só aparece no sitemap | Integrá-la à navegação ou a links contextuais |

Um sitemap XML é uma indicação para descoberta; seu envio não garante rastreamento ou indexação. Uma página HTML também não garante melhor posição na busca.

Para investigar uma URL específica, use a inspeção no Search Console. O artigo sobre [dados atrasados no Search Console](/blog/search-console-dados-atrasados/) explica por que isso é diferente de esperar o relatório de desempenho atualizar.

## No DejotaCode

Antes de criar uma página adicional, devemos verificar se categorias, trilhas, Store, busca e links contextuais já oferecem descoberta suficiente.
