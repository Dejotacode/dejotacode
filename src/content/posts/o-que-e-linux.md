Linux é o núcleo de sistemas operacionais usados em computadores, servidores e outros dispositivos. No dia a dia, o nome também é usado para falar do sistema completo instalado no computador, como Ubuntu, Linux Mint ou Fedora.

Se você quer aprender Linux, comece entendendo três coisas: o que ele faz, o que é uma distribuição e como experimentar sem substituir imediatamente o sistema que já usa.

## O que o Linux faz no computador?

O núcleo do sistema, chamado **kernel**, administra recursos como memória e processador e permite que os programas trabalhem com o hardware. Ele faz parte do sistema que sustenta as tarefas que você executa.

Ao abrir um arquivo, por exemplo, você interage com um aplicativo e uma interface. Por trás dessa ação, diferentes componentes do sistema trabalham juntos para acessar e apresentar os dados. O kernel é uma dessas peças; ele não é, sozinho, a área de trabalho que aparece na tela.

A própria organização do kernel distingue o Linux de uma distribuição, que reúne os componentes de um sistema completo. [Referência: kernel.org](https://www.kernel.org/linux.html)

## O que é uma distribuição Linux?

Uma distribuição combina o kernel Linux com ferramentas, bibliotecas e programas. Distribuições para computadores pessoais normalmente também oferecem instalador, interface gráfica e meios de instalar e atualizar aplicativos.

Ubuntu, Linux Mint e Fedora são exemplos. Elas compartilham a base Linux, mas podem apresentar diferenças na aparência, nos programas incluídos, nas atualizações e no suporte disponível.

Pense na escolha a partir das suas necessidades: quais tarefas você quer realizar, quais programas precisa usar e qual computador tem disponível. Você não precisa experimentar dezenas de opções para começar.

Para aprofundar essa decisão, veja [como escolher uma distribuição Linux](/blog/como-escolher-distribuicao-linux/).

## Linux não é apenas uma tela de terminal

Em uma distribuição com interface gráfica, você pode abrir pastas, navegar na internet e ajustar configurações usando janelas, menus e o mouse.

O terminal é outra forma de interagir com o sistema. Nele, você escreve comandos para executar tarefas. Ele se torna útil quando você precisa repetir uma operação, investigar um problema ou seguir uma instrução técnica com precisão.

Você pode aprender aos poucos. Um primeiro exercício é abrir o terminal e executar:

```bash
pwd
```

Esse comando mostra o caminho do diretório atual. Um resultado ilustrativo seria `/home/ana`; o nome e o caminho no seu computador podem ser diferentes. O comando apenas mostra uma informação, sem alterar seus arquivos.

Depois, siga o tutorial de [comandos Linux para quem está começando](/blog/comandos-linux-para-iniciantes/), com exemplos de navegação por pastas.

## Para que aprender Linux?

Linux pode ser uma oportunidade para entender melhor como um computador organiza arquivos, executa programas e controla o acesso aos dados. Esses conceitos também aparecem quando você estuda programação ou administra um servidor.

No uso pessoal, vale explorar se uma distribuição atende às suas tarefas de estudo e trabalho. Antes de migrar, confira a disponibilidade dos aplicativos de que depende e a compatibilidade dos seus equipamentos. Um programa usado no Windows não deve ser considerado compatível automaticamente.

Para definir um objetivo concreto, escolha algo pequeno: localizar seus documentos, instalar um aplicativo pelos meios da distribuição ou aprender a interpretar uma mensagem de erro. Isso torna o aprendizado mais fácil de acompanhar.

## Como experimentar antes de instalar

Uma possibilidade é testar uma distribuição em uma máquina virtual, que executa um ambiente separado dentro do sistema atual. Outra é usar uma sessão **live**, iniciada por um pendrive preparado para isso, quando a distribuição oferece esse recurso.

O Ubuntu, por exemplo, oferece a opção de experimentar o ambiente antes de instalar. Nesse teste, você pode observar a interface e conferir recursos como rede, áudio e vídeo. A experiência pelo pendrive pode ter desempenho diferente da instalação no disco. [Guia oficial para experimentar o Ubuntu](https://ubuntu.com/desktop/docs/en/26.04/tutorial/try-ubuntu-desktop/)

Preparar o pendrive pode apagar seu conteúdo. Antes de criar a mídia, confirme o dispositivo escolhido e guarde seus arquivos. Durante a sessão de teste, evite iniciar a instalação ou alterar partições se o objetivo é apenas conhecer o sistema. Faça backup antes de qualquer instalação.
