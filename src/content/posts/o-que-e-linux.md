Linux é a base de diferentes sistemas operacionais usados em computadores, servidores e muitos outros dispositivos.

## Linux não é apenas uma tela preta

Você pode usar Linux com janelas, menus e aplicativos comuns. O terminal é uma ferramenta adicional: ele permite dar instruções por texto e entender melhor o que o sistema está fazendo.

## O que é uma distribuição

Uma distribuição reúne o Linux, instalador, interface, programas e sistema de atualizações. Ubuntu, Linux Mint e Fedora são exemplos conhecidos, mas você não precisa testar todos para começar.

## Por que aprender

O contato com Linux ajuda a compreender arquivos, permissões, programas e redes. Esse conhecimento é útil em programação, segurança e administração de servidores.
