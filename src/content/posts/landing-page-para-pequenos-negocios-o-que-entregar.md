Landing page pode ser um bom primeiro serviço para quem está começando com desenvolvimento web.

O escopo pode ser menor que um site completo e o resultado é fácil de mostrar.

Mas “uma página” não significa “trabalho simples em qualquer situação”.

Você precisa definir o que será entregue.

## O que é uma landing page?

Neste contexto, é uma página focada em apresentar:

- uma empresa;
- um profissional;
- um serviço;
- uma oferta;
- uma ação principal.

Para um pequeno negócio, pode reunir:

- apresentação;
- benefícios;
- serviços;
- prova social real;
- contato;
- WhatsApp;
- localização.

## Comece pelo objetivo

Pergunte:

> O que a pessoa deve fazer depois de ler?

Possíveis ações:

- chamar no WhatsApp;
- enviar formulário;
- ligar;
- visitar local;
- solicitar orçamento.

Uma página sem objetivo vira apenas catálogo.

## Estrutura simples

Uma landing page pode ter:

### 1. Hero

- proposta;
- descrição;
- CTA.

### 2. Problema ou contexto

Explique por que o serviço existe.

### 3. Serviços ou benefícios

Liste os principais.

### 4. Como funciona

Mostre processo.

### 5. Provas reais

Se existirem:

- depoimentos autorizados;
- avaliações;
- fotos;
- cases.

Nunca invente.

### 6. Sobre

Apresente negócio.

### 7. Contato

WhatsApp, formulário ou telefone.

## O que pedir ao cliente

Antes de começar:

- nome;
- logo;
- cores;
- textos;
- lista de serviços;
- fotos;
- contato;
- endereço;
- redes;
- domínio;
- referências.

Crie checklist.

## Mobile primeiro na prática

Muitos clientes serão acessados pelo celular.

Teste:

- tamanho dos textos;
- botões;
- espaçamento;
- imagens;
- formulário;
- WhatsApp;
- menu.

## Velocidade importa

Evite:

- imagens enormes;
- vídeos automáticos;
- bibliotecas desnecessárias;
- animações pesadas.

Uma página simples deve carregar rápido.

## SEO básico

Mesmo uma landing page deve ter:

- title;
- description;
- headings;
- canonical;
- texto real;
- alt em imagens;
- sitemap quando aplicável.

SEO não é garantia de ranking.

É base técnica.

## Formulário

Se usar formulário:

- peça só o necessário;
- informe consentimento quando aplicável;
- trate erros;
- proteja contra spam;
- confirme sucesso.

Não colete dados sem motivo.

## WhatsApp

Um CTA de WhatsApp pode ser útil.

Deixe mensagem inicial clara.

Exemplo:

> Olá! Vi sua página e gostaria de solicitar um orçamento.

## Domínio e hospedagem

Defina quem paga e quem controla.

Prefira que domínio importante fique na conta do cliente.

Documente acessos.

## Analytics

Se usar:

- explique;
- respeite privacidade;
- não instale ferramentas demais.

Para um projeto inicial, métricas básicas podem bastar.

## O que não deve entrar automaticamente

Não presuma que uma landing inclui:

- logo;
- copy completa;
- fotografia;
- anúncios;
- automação;
- CRM;
- SEO avançado;
- manutenção.

Cada item precisa estar no orçamento.

## Revisões

Defina quantidade.

Exemplo:

> Uma rodada de revisão com ajustes de texto, imagens e pequenos detalhes visuais.

Mudanças estruturais podem gerar novo escopo.

## Entrega técnica

Antes de finalizar:

- testar links;
- testar formulário;
- testar WhatsApp;
- testar desktop;
- testar tablet;
- testar mobile;
- validar HTTPS;
- revisar textos;
- conferir favicon;
- testar 404 quando necessário;
- verificar domínio.

## Entrega ao cliente

Envie:

- URL;
- resumo;
- acessos;
- orientações;
- itens pendentes;
- limite de suporte.

Se possível, grave vídeo curto mostrando.

## Exemplo de escopo

> Landing page com até seis seções, responsiva, formulário simples, CTA de WhatsApp, configuração básica de SEO, publicação e uma rodada de revisão.

Isso é entendível.
