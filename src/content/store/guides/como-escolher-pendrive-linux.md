Mais importante que procurar um “melhor pendrive” universal é entender o que você pretende fazer com ele.

Para criar uma mídia bootável e testar Linux, capacidade, velocidade, compatibilidade com o seu computador e procedência do produto são critérios mais úteis que aparência ou promessa de desempenho.

## Backup antes de instalar

Se você pretende instalar Linux no computador, faça uma cópia dos arquivos importantes antes de começar. Um SSD externo pode ajudar nessa tarefa, mas tem uma finalidade diferente do pendrive usado para criar a mídia de instalação.

A [análise do SanDisk Portable SSD 1 TB](/store/sandisk-portable-ssd-1tb/) apresenta uma opção de armazenamento para backup. Essa indicação é complementar; não é uma recomendação de pendrive nem um requisito para testar Linux.
