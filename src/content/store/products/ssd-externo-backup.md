Antes de alterar um sistema operacional, ter uma cópia dos arquivos importantes reduz bastante o risco de uma decisão apressada virar perda de dados.

A DejotaStore tratará SSD externo como ferramenta de backup e organização, não como item obrigatório para aprender Linux.
