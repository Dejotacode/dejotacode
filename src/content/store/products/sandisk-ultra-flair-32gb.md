O **SanDisk Ultra Flair 32 GB USB 3.0**, modelo **SDCZ73-032G-G46**, é uma recomendação editorial para quem precisa criar uma mídia bootável Linux.

A SanDisk informa interface USB 3.0, conector USB-A e leitura sequencial de até 150 MB/s. Para o nosso uso, o ponto principal é simples: 32 GB oferecem espaço suficiente para muitas imagens de distribuições Linux e ainda deixam margem para reutilização posterior.
