# Matriz Oficial — Conteúdo + Afiliados + Vídeos v1

Data de referência: 29/09/2026

## Objetivo

Conectar conteúdo educativo, produtos próprios, recomendações afiliadas e vídeos sem transformar o DejotaCode em catálogo de ofertas.

Regra central:

Problema real → conteúdo útil → recomendação contextual → transparência → medição.

## Princípios

- Produto próprio vem antes de afiliado quando resolve diretamente o problema.
- Hotmart é usado para aprofundamento educacional quando houver aderência.
- Shopee é usada apenas para ferramentas físicas úteis ao conteúdo.
- Nenhum item é apresentado como testado ou revisado pelo DejotaCode sem uso real.
- Links afiliados devem manter identificação comercial e rastreamento.
- Não inserir produto em artigo apenas porque existe comissão.
- Preço, estoque e condições de terceiros são variáveis e devem ter data de revisão.
- Métrica principal não é clique isolado: é avanço coerente no funil.

## Critério de decisão

Depois de acumular dados suficientes, comparar:

1. visitas ao conteúdo;
2. avanço para trilha/produto próprio;
3. cliques afiliados por recurso;
4. origem da aquisição;
5. conversões Hotmart confirmadas;
6. relatórios de comissão da Shopee.

Não aumentar a quantidade de produtos afiliados apenas por volume de cliques. Aumentar apenas quando houver contexto editorial, interesse real e sinal de utilidade para o leitor.
