# Linux do Zero — Capítulo 2

## Escolhendo sua primeira distribuição

No capítulo anterior, você entendeu que Linux não é um único sistema pronto. Existem distribuições diferentes, cada uma reunindo o kernel Linux com programas, instalador, interface gráfica e decisões feitas por uma comunidade ou empresa.

Agora vem uma dúvida que trava muita gente logo no começo:

**Qual distribuição eu escolho?**

A resposta curta é: você não precisa encontrar a distribuição perfeita. Precisa encontrar uma opção estável, compatível com o seu computador e fácil de manter enquanto aprende.

> **VOCÊ NÃO PRECISA DECORAR**
> Ubuntu, Mint, Fedora, Debian e outros nomes parecem muitos no início. Você não precisa entender todos agora. Neste capítulo, vamos usar critérios simples para reduzir as opções.

## O que você vai conseguir fazer

Ao terminar este capítulo, você será capaz de:

- entender quais critérios realmente importam para um iniciante;
- eliminar opções que complicariam sua primeira experiência;
- identificar quando uma versão estável faz mais sentido do que uma versão de teste;
- escolher uma distribuição para experimentar sem transformar a decisão numa aposta definitiva.

## Não escolha pela aparência da captura de tela

É comum conhecer uma distribuição por um vídeo bonito ou por uma captura de tela cheia de efeitos. Isso pode despertar curiosidade, mas não é um bom critério de escolha.

A interface pode ser personalizada depois. O que mais importa no começo é outra coisa: atualização simples, documentação acessível, comunidade ativa e compatibilidade com o seu equipamento.

> **ENTENDA**
> Pense na distribuição como a combinação entre carro, manual e rede de assistência. A pintura chama atenção, mas para aprender a dirigir você se beneficia muito mais de um veículo previsível, com peças disponíveis e bastante gente que sabe explicar como ele funciona.

## Critério 1 — Seu computador precisa ser atendido

Antes de pensar em nomes, observe o equipamento que você realmente vai usar.

Anote:

- quantidade de memória RAM;
- espaço disponível em disco;
- idade aproximada do computador;
- fabricante da placa de vídeo, se houver uma dedicada;
- se você depende de algum periférico muito específico.

Não precisa virar especialista em hardware. O objetivo é apenas evitar instalar uma opção pesada demais ou descobrir tarde que algum componente exige cuidado extra.

> **DICA DO DEJOTA**
> Se o computador já roda um sistema moderno de forma confortável, ele provavelmente consegue experimentar várias distribuições atuais. Em máquinas mais antigas, vale priorizar ambientes gráficos mais leves e verificar os requisitos oficiais antes do download.

## Critério 2 — Prefira uma versão estável

Para aprender, previsibilidade costuma valer mais do que novidade.

Alguns projetos oferecem versões estáveis e, ao mesmo tempo, versões de teste ou beta. Essas versões de teste existem para quem quer experimentar novidades e ajudar a encontrar problemas antes do lançamento final.

Se este é o seu primeiro contato com Linux, a regra é simples:

**prefira a versão estável recomendada pelo próprio projeto.**

Isso reduz a chance de encontrar um erro que você ainda não sabe diferenciar de uma configuração normal.

> **ATENÇÃO**
> “Mais novo” não significa automaticamente “melhor para começar”. Uma versão beta pode ter recursos interessantes e ainda assim exigir paciência para lidar com falhas temporárias.

As versões mudam com o tempo. Por isso, antes de baixar, consulte sempre a página oficial da distribuição e procure a edição estável e suportada. Quando esta edição do livro precisar citar uma versão específica, ela aparecerá como referência da edição — não como regra permanente.

## Critério 3 — Documentação e comunidade importam

Quando surgir uma dúvida, você vai procurar respostas. Nesse momento, uma distribuição com documentação clara e muita gente usando ajuda bastante.

Você não precisa escolher a opção com a maior comunidade do mundo. Mas é útil que existam:

- documentação oficial atualizada;
- fóruns ou comunidades ativas;
- tutoriais recentes;
- respostas suficientes para problemas comuns.

Quanto mais fácil for confirmar uma informação em fonte oficial, melhor para quem está começando.

## Critério 4 — Facilidade de manutenção

Depois da instalação, você vai precisar atualizar o sistema, instalar programas e, de vez em quando, resolver pequenos problemas.

Para a primeira experiência, prefira uma distribuição que torne essas tarefas previsíveis.

Isso não significa que tudo precisa acontecer por interface gráfica. Significa que você deve conseguir entender o que está acontecendo sem depender de receitas obscuras.

> **ENTENDA**
> Uma boa primeira distribuição não é aquela que esconde tudo. É aquela que permite aprender sem transformar cada atualização numa aventura.

## Quatro opções que aparecem muito

Você provavelmente encontrará estes nomes durante sua pesquisa:

### Linux Mint

O Linux Mint usa por padrão uma interface de desktop tradicional, com menu, painel e uma organização que pode parecer familiar para quem vem do Windows. O projeto também oferece ferramentas gráficas voltadas ao uso diário em desktop.

### Ubuntu

É uma das distribuições mais conhecidas no desktop e possui grande quantidade de documentação, tutoriais e suporte comunitário. As edições LTS são pensadas para quem prefere ciclos mais longos de suporte.

### Fedora Workstation

Traz tecnologias recentes com uma experiência de desktop moderna e organizada. Pode interessar a quem quer aprender usando um sistema com novidades frequentes e documentação ativa.

### Debian

É conhecido por priorizar estabilidade e serve de base para várias outras distribuições. É uma opção sólida, embora algumas etapas de configuração e escolha de software possam exigir mais contexto de quem está começando.

Nenhuma dessas descrições significa “melhor” ou “pior”. Elas mostram perfis diferentes.

| Se sua prioridade é... | Vale conhecer primeiro |
|---|---|
| seguir as telas e práticas deste livro | Ubuntu LTS |
| uma interface de desktop mais tradicional | Linux Mint |
| tecnologias recentes em uma versão estável | Fedora Workstation |
| uma base conhecida por estabilidade | Debian |

> **ENTENDA**
> Esta tabela não é um ranking. É apenas um mapa para reduzir sua pesquisa.

> **DICA DO DEJOTA**
> Se você está completamente perdido, reduza a decisão para duas perguntas: “Meu computador roda esta distribuição com conforto?” e “Consigo encontrar documentação clara quando tiver uma dúvida?”. Isso já elimina muita confusão.

## E qual eu usaria para acompanhar este livro?

Para manter exemplos, capturas de tela e práticas consistentes, esta edição usará **Ubuntu LTS** como distribuição de referência. Isso não significa que Ubuntu seja “a melhor distribuição” nem que o conteúdo só funcione nela.

A escolha é editorial: buscamos uma versão estável e suportada, instalação amigável, boa experiência em desktop e documentação abundante. Quando houver diferença relevante para outras distribuições, ela será indicada.

## Faça comigo — reduza suas opções

Pegue papel, bloco de notas ou um arquivo de texto e responda:

1. Meu computador é relativamente novo ou antigo?
2. Quero uma experiência mais parecida com desktop tradicional?
3. Prefiro suporte de longo prazo ou novidades mais frequentes?
4. Quero muita documentação para pesquisar sozinho?
5. Estou disposto a lidar com ajustes extras ou quero começar pelo caminho mais previsível?

Agora escolha no máximo **duas distribuições** para testar.

Não escolha cinco. A ideia não é montar um campeonato; é reduzir a indecisão. Depois do teste em modo live, escolha **uma** delas para acompanhar os próximos capítulos e ganhar consistência durante o aprendizado.

## Teste antes de instalar

Muitas distribuições oferecem uma imagem “live”, capaz de iniciar pelo pendrive sem instalar imediatamente no disco.

Esse modo serve para experimentar interface, Wi-Fi, teclado, áudio, vídeo e outros componentes antes de alterar o computador.

> **ATENÇÃO**
> Iniciar uma sessão live não é a mesma coisa que instalar. No próximo capítulo vamos preparar backup, pendrive e testes com calma antes de qualquer mudança no disco.

## Erros comuns ao escolher

### Escolher porque alguém disse que “usuário de verdade usa X”

Isso é identidade de grupo, não critério técnico.

### Trocar de distribuição toda semana

Você aprende menus diferentes, mas não aprofunda os fundamentos. Escolha uma, use por um tempo e só troque quando houver motivo concreto.

### Escolher uma versão beta sem perceber

Leia a página oficial de download. Procure termos como stable, LTS ou versão recomendada e trate beta/testing como ambientes de teste.

### Ignorar o backup porque “é só um teste”

Testar pelo modo live é uma ótima forma de reduzir risco, mas qualquer etapa que envolva instalação posterior merece backup. Confiança não substitui cópia dos seus arquivos importantes.

## Teste você mesmo

Escolha duas distribuições entre as opções que pesquisou e abra apenas os sites oficiais.

Para cada uma, anote:

- nome da versão estável atual;
- se há edição LTS ou suporte prolongado;
- requisitos mínimos ou recomendados;
- se existe modo live;
- onde fica a documentação oficial.

Depois responda em uma frase por distribuição: **por que ela parece adequada ou inadequada para o seu computador?**

O objetivo não é acertar uma resposta universal. É praticar uma decisão baseada em critérios.
