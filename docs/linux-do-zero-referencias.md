# Referências e recursos oficiais

Este livro foi pensado para iniciantes, mas informação técnica muda com o tempo. Quando uma tela, versão ou procedimento estiver diferente, comece pela documentação oficial do projeto que você está usando.

## Fontes principais

- **Ubuntu Desktop Documentation** — instalação, configuração inicial, atualizações e uso do Ubuntu.
  <https://documentation.ubuntu.com/desktop/>

- **Ubuntu — Install Ubuntu Desktop** — referência oficial do processo de instalação.
  <https://ubuntu.com/tutorials/install-ubuntu-desktop>

- **The Linux Kernel Documentation** — documentação oficial do kernel Linux.
  <https://docs.kernel.org/>

- **GNU Coreutils** — referência dos utilitários fundamentais de arquivos, texto e sistema usados no terminal.
  <https://www.gnu.org/software/coreutils/manual/>

- **Debian Documentation** — guias, referência, instalação e notas de versão do Debian.
  <https://www.debian.org/doc/>

- **Linux Mint Documentation** — guia de instalação, guia do usuário e solução de problemas.
  <https://linuxmint.com/documentation.php>

## Para continuar estudando

- **ArchWiki** — referência técnica ampla e muito útil, inclusive para quem usa outras distribuições. Alguns procedimentos são específicos do Arch Linux; compare sempre com a documentação da sua distribuição.
  <https://wiki.archlinux.org/>

- **Manual local do sistema** — no terminal, use `man comando` para consultar a documentação instalada da ferramenta.

> **DICA DO DEJOTA**
> Não tente memorizar toda a documentação. Aprender a localizar a fonte certa, verificar a versão e entender o que será alterado é uma habilidade mais valiosa.
