# Etapa 9 — Testes, responsividade e acessibilidade

Esta etapa adiciona uma auditoria automática para todas as páginas HTML geradas. Ela verifica idioma, viewport responsivo, título, descrição, região principal, atalho de teclado, IDs duplicados, texto alternativo de imagens e navegação atual.

Também foram adicionados foco visível, suporte à preferência por movimento reduzido, melhorias para alto contraste e indicação correta da página atual no menu.

Execute `npm run test:quality` na raiz para gerar e auditar o site.
