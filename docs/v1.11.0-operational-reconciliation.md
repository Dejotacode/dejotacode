# v1.11.0 — Reconciliação operacional pós-Admin Editorial

## Objetivo

Alinhar documentação, roadmap e runbooks ao estado efetivamente homologado nas releases frontend v1.10.0 e API v1.6.0, sem alterar funil, CTAs ou taxonomia de analytics.

## Estado homologado

- Frontend: v1.10.0, Git/Markdown canônico.
- API: v1.6.0, repositório `Dejotacode/dejotacode-api`.
- Admin: autenticação, métricas e Editor Editorial.
- Mídia: R2 com metadados no D1.
- Publicação: branch `content/admin-*` → PR → CI → merge protegido por SHA → push `main` → Pages → smoke.

## Reconciliações desta etapa

- documentação de arquitetura passa a refletir o Admin Editorial e R2;
- runbook operacional passa a refletir deploy automático do Pages após push em `main`;
- fluxo editorial passa a documentar GitHub, CI, `expectedHeadSha` e mídia R2;
- documentos históricos v1.9 recebem atualização sem apagar o contexto original;
- Issue #46 pode ser encerrada com evidência da v1.10.0.

## Baseline de crescimento preservado

Nenhuma mudança de conversão é parte desta etapa. Os checkpoints previstos para a linha v1.7/v1.8 continuam em 23/09/2026 (D+7) e 30/09/2026 (D+14), sujeitos a volume suficiente.

Até esses checkpoints, não alterar CTA, funil guia/newsletter, campanhas nem nomes de eventos sem necessidade operacional comprovada.
