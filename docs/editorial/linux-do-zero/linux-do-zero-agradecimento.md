# Obrigado por chegar até aqui

Se você começou este livro com curiosidade, insegurança ou até um pouco de medo de “quebrar alguma coisa”, espero que agora o Linux pareça menos distante.

Você não precisa decorar todos os comandos, conhecer todas as distribuições ou resolver qualquer problema sozinho. O objetivo sempre foi outro: **entender o que está fazendo, praticar com segurança e ganhar autonomia aos poucos.**

Cada instalação concluída, cada comando compreendido e cada problema investigado com calma faz parte desse processo.

Continue experimentando. Continue perguntando. E, quando algo não fizer sentido, volte ao básico: leia a mensagem, procure uma fonte confiável e faça uma mudança de cada vez.

Obrigado por confiar no **Linux do Zero** e no **DejotaCode** para acompanhar esse começo.
