## Short 1 — O que é um pendrive bootável?

Duração alvo: 35–45 segundos.

Gancho:
“Copiar a ISO para o pendrive não transforma ele em um pendrive bootável.”

Narração:
“Um pendrive bootável é preparado para iniciar o computador com outro sistema operacional. No caso do Linux, você grava a imagem do sistema usando uma ferramenta própria, como Rufus no Windows ou Discos no Ubuntu. Isso é diferente de simplesmente copiar o arquivo ISO. E atenção: durante a criação, o conteúdo do pendrive é apagado. Antes de confirmar, confira o tamanho e o nome do dispositivo. No DejotaCode eu deixei o passo a passo completo para fazer isso com segurança.”

## Short 2 — 3 cuidados antes de instalar Linux

Duração alvo: 40–50 segundos.

Gancho:
“Antes de instalar Linux, três cuidados podem evitar uma dor de cabeça enorme.”

Narração:
“Primeiro: faça backup dos arquivos importantes. Segundo: quando for criar o pendrive bootável, confirme o tamanho do dispositivo antes de gravar a imagem — escolher o disco errado pode apagar dados. Terceiro: não precisa instalar de primeira. Distribuições como Ubuntu permitem testar o sistema pelo pendrive e conferir Wi-Fi, áudio, teclado e vídeo antes de alterar o disco do computador. O objetivo não é instalar rápido. É entender cada etapa antes de confirmar.”
