# DejotaCode v1.3.0 — Release Notes

A v1.3.0 consolida a fundação operacional criada após a v1.2.0 e amplia o DejotaCode em quatro frentes: conteúdo editorial, portfólio, conversão e refinamentos técnicos.

## Destaques

- CI automático com `npm ci`, `npm run check` e `npm run build:production`.
- Documentação técnica e operacional consolidada no README e em `docs/`.
- Analytics first-party para `page_view` e `cta_click`, sem cookies, fingerprinting ou persistência de PII no frontend.
- 10 novos conteúdos editoriais para iniciantes, elevando a base atual de 7 para 17 conteúdos.
- Quatro trilhas disponíveis: Linux, Programação, IA e Segurança Digital.
- Case completo do DejotaCode na página de portfólio, baseado em entregas verificáveis.
- CTA contextual nos artigos para conduzir o visitante à trilha relacionada ou à newsletter.
- Refinamentos de sitemap, Open Graph fallback e compressão HTML.
- Revisão visual automatizada em desktop/mobile e temas claro/escuro, sem overflow horizontal ou falhas estruturais nas rotas auditadas.

## Operação e qualidade

- `main` passou pelos gates de CI após cada bloco do P1.
- Build estático atual gera 38 páginas.
- A revisão visual cobriu homepage, blog, trilhas, artigo, trilha de programação, portfólio e newsletter em 28 combinações de viewport/tema.
- Nenhuma mudança de backend, API, D1, Cloudflare, tag, release ou deploy foi incluída na preparação desta versão.

## Comparação com v1.2.0

Antes do commit de versionamento, a `main` estava 22 commits à frente da tag `v1.2.0`, sem divergência, com 24 arquivos alterados no conjunto de mudanças acumuladas.
