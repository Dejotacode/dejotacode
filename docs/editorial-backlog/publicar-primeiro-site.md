# Brief — Como publicar seu primeiro site

## Papel editorial

- Categoria: Programação
- Trilha candidata: Primeiros passos na programação
- Nível: iniciante
- Tipo: tutorial passo a passo
- Leitura estimada: 12–15 min

## Título recomendado

**Como publicar seu primeiro site gratuitamente: passo a passo para iniciantes**

## Intenção

Responder buscas como:
- como publicar site grátis;
- como colocar site na internet;
- hospedagem grátis para HTML;
- publicar site HTML e CSS;
- como hospedar meu primeiro site.

## Promessa

Levar o leitor de uma página local para um projeto versionado e publicado, entendendo arquivos, hospedagem, domínio, Git, GitHub e deploy.

## Estrutura

1. Seu site existe, mas só no seu computador.
2. Arquivos, hospedagem e domínio.
3. Checklist antes de publicar.
4. Salvar o projeto com Git.
5. Enviar para o GitHub.
6. Escolher hospedagem gratuita.
7. Conectar o repositório.
8. Primeiro endereço público.
9. Atualizar: editar → commit → push → deploy.
10. Introdução a domínio próprio.
11. Erros comuns.
12. Resultado: projeto online e compartilhável.

## Plataforma de exemplo

Cloudflare Pages é candidata natural por ser usada no DejotaCode, com GitHub Pages como alternativa editorial.

Antes da publicação, validar documentação e interface atuais do serviço escolhido.

## Cuidados técnicos

Antes de publicar, verificar:
- fluxo atual do Cloudflare Pages;
- integração atual com GitHub;
- limites vigentes do plano gratuito;
- URLs e passos da interface.

## Objetivo pedagógico

Levar o leitor de “eu fiz uma página no meu computador” para “eu tenho um projeto versionado e publicado que posso compartilhar”.
