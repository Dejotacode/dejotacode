## Papel editorial

- Categoria: Linux & Segurança
- Trilha candidata: Segurança digital essencial

- Leitura estimada: 10–12 min

## Título recomendado

**Backup para iniciantes: como proteger seus arquivos sem complicação**

## Intenção

Responder dúvidas como:
- o que é backup;
- como fazer backup;
- diferença entre backup e nuvem;
- onde guardar cópias;
- regra 3-2-1;
- como evitar perder arquivos.

## Promessa

Ao terminar, o leitor deve entender o que é backup, por que sincronização não é a mesma coisa, como criar uma estratégia simples e como testar uma restauração.

## Estrutura

1. Backup é uma cópia de segurança.
2. Sincronização não é backup.
3. O que realmente merece backup.
4. Regra 3-2-1 sem complicação.
5. Exemplo prático para um iniciante.
6. Frequência: quanto trabalho você aceita perder?
7. Como testar a restauração.
8. Cuidados com HDs e pendrives.
9. Segurança dos backups.
10. Checklist final.

## Mensagem central

> Sincronizar ajuda a manter arquivos disponíveis. Backup ajuda a recuperá-los quando alguma coisa dá errado.
